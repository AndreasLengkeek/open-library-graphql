# 05.5 updateProfile

## Goal
The Viewer can change their own `displayName` and `bio`.

## Notes
- The Viewer can only update their own profile, so there's no `id` argument. Ownership comes from the token. Compare this with 05.3 and 05.4, where the mutation takes an id. When do you prefer each style?
- Validate the lengths (for example `displayName` 1–50 characters, `bio` ≤ 500).

## Acceptance criteria
- [ ] It works through the router; without a token → `UNAUTHENTICATED`.
- [ ] Tests for validation and success.

## Concepts practised
Implicit vs explicit ownership in mutation design
