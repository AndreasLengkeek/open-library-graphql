# 03.3 The `me` query end to end

## Goal
The milestone 3 target query works through the router with a real token:

```graphql
query MyShelves {
  me { displayName shelves { name kind books { title authors { name } } } }
}
```

## Notes
- `me` resolves the Viewer in `users`. Everything after that is federation doing its job.
- Without a token, `me` is `null` (not an error), unless your design says otherwise.
- Add an end-to-end test script (`pnpm e2e`) that starts the stack, logs in as the seeded `andreas`, and runs `MyShelves`. It can use the real Open Library, since it's not part of `pnpm test`.

## Acceptance criteria
- [ ] `MyShelves` returns `andreas`'s seeded Shelves, with titles and Authors.
- [ ] The router's logs or Sandbox show requests to all three subgraphs for this one operation.

## Concepts practised
Entity resolution across three subgraphs · Viewer-scoped root fields
