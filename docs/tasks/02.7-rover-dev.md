# 02.7 Compose with rover dev

## Goal

All three subgraphs run behind a local Apollo Router, and a cross-subgraph query works from Apollo Sandbox.

## Notes

- `pnpm dev` starts the three subgraphs (for example with `concurrently`), then
  `rover dev --supergraph-config router/supergraph.yaml --router-config router/router.yaml`.
- `router.yaml` can be almost empty for now. 03.2 adds header forwarding.
- `rover dev` doesn't need a GraphOS key, and it re-composes when a subgraph's schema changes.
- `me` doesn't work yet, so use `user(username: "andreas")` for cross-subgraph queries until M3.

## Acceptance criteria

- [x] Sandbox at `http://localhost:4000` shows the composed schema.
- [x] `user(username: "andreas") { displayName shelves { name books { title authors { name } } } }` returns seeded data, resolved across all three subgraphs.
- [x] Editing a subgraph's `schema.graphql` while `rover dev` is running causes the router to re-compose.

## Concepts practised

`rover dev` · local supergraph development loop · running a query that spans every subgraph
