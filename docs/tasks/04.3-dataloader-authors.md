# 04.3 DataLoader for Authors

## Goal
Apply DataLoader where the upstream API **can't** batch (`/authors/<id>.json` takes one Author at a time), and measure what it still gives you.

## Notes
- The batch function runs one request per *distinct* key, all at once (`Promise.all`). Consider a concurrency limit (for example `p-limit` at 5) to be polite to Open Library.
- What you gain: **de-duplication** (Tolkien on 3 Books → 1 request) and **concurrency** (requests run in parallel instead of one after another). You don't gain fewer requests per distinct Author.
