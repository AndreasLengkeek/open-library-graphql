# 00.1 Repo scaffold

## Goal
An empty pnpm monorepo, set up for Node 26 and TypeScript, with a place for each subgraph and the router. Running `pnpm test` succeeds even though there's nothing to test yet.

## Notes
- **Fix pnpm first.** Corepack currently points at a missing `pnpm@12.10.1` and crashes. Run `corepack prepare pnpm@latest --activate` (or `corepack install`), then pin the version with `"packageManager"` in the root `package.json`.
- Layout:
  ```
  services/users/  services/catalog/  services/library/   # each its own package
  router/                                                  # supergraph.yaml, router.yaml (no package)
  docs/  SPEC.md  GLOSSARY.md
  ```
- Root `tsconfig.base.json` with `strict: true`, `module`/`moduleResolution: "NodeNext"` and `target: "ES2024"`. Each service extends it.
- Add an `.nvmrc` or `engines` entry for Node 26.
- Vitest at the root with a workspace config, so `pnpm test` runs every package.
- `better-sqlite3`, `@libsql/client` and `node:sqlite` were all checked against Node 26.8.1 on this machine: they install from prebuilt binaries and work.
- `git init` and add a `.gitignore` covering `node_modules`, `*.db` and `.env`.

## Acceptance criteria
- [x] `pnpm -v` works without the corepack error.
- [x] `pnpm install` completes at the root.
- [x] `pnpm -r exec tsc --noEmit` passes for all three (empty) services.
- [x] `pnpm test` runs Vitest and exits 0, with one placeholder test per service.

## Concepts practised
pnpm workspaces · TypeScript project setup for ESM on Node · Vitest workspaces
